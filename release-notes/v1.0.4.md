# PixivPlus 1.0.4 更新日志

## 新增

- **侧边栏精简**：主页左侧抽屉菜单末尾新增「精简侧边栏 / 恢复全部菜单」按钮，一键隐藏低频菜单项（投稿作品、你的作品、收藏、书签、关注 / 粉丝等）
  - 隐藏清单可在「设置 → 侧边栏精简」逐项勾选（分组标题同样可选），默认隐藏 8 项
  - 主开关默认关闭；宿主会动态重建菜单，个别条目可能残留，重启 Pixiv 后完全生效
- **屏蔽设定页入口**：宿主「屏蔽设定」页底部新增「PixivPlus 屏蔽项管理」，点按直达模块过滤规则页
  - 本地过滤主开关关闭时不显示；面板内按返回键直接回到屏蔽设定页
- **快捷屏蔽确认弹窗**：详情页「屏蔽当前作者 / 屏蔽当前标题」点击后先弹确认窗，展示将写入的规则与撤销方式，确认后才会写入；目标已在规则中时提示且不重复添加

## 修复

- **首次打开详情页时被屏蔽的简介不显示**（App 商店合规会隐藏含外链的简介）：重写为三层恢复管线
  - 详情响应注入：本地简介索引命中时直接注入响应（0ms），由 App 自行渲染
  - 异步网页预取：索引未命中时后台请求网页版接口，不阻塞页面加载
  - 渲染层回填：遍历当前页全部简介控件逐一渲染，详情 Pager 多实例不再漏显示
  - 注入内容自动清洗外链标签，避免被 App 渲染层剥成空白
  - 深链打开、列表点进、重进详情三种场景均已实测恢复
- 左右滑动切换插画后，新作品简介可能不回填的问题
- 重进详情页时简介恢复变慢的问题（现直接走本地索引注入）

## 改进

- CI：GitHub Release 附件与构建产物统一命名为 `PixivPlus-<版本号>.apk`
- 启动日志与诊断页新增模块构建指纹，便于确认设备上实际安装的构建版本
- 诊断统计：无关 API 响应不再计入「已处理请求数」
