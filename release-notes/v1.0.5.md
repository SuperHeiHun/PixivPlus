# PixivPlus 1.0.5 更新日志

## 新增

- **备份内容范围设置**：设置项、屏蔽规则（关键词 / 标签 / 作者）、历史记录（含作者资料）可分别选择是否保存；未包含的部分在恢复时保留本机现有数据。
- **可选备份密码加密**：本地与 WebDAV 备份均支持 AES-256-GCM 加密，使用 PBKDF2-HMAC-SHA256 派生密钥，并为每次备份生成随机盐与 IV。
  - 备份密码不写入备份文件；恢复时可输入密码解密，密码错误或文件被修改时校验失败。
  - 留空时仍保存明文 JSON；忘记密码将无法恢复加密备份，请妥善保管。
- **关于页构建信息**：显示构建时间与构建指纹，便于确认实际安装的版本。

## 隐私改进

- API 响应日志不再输出内容片段，也不再将响应体写入调试缓存文件。
- 搜索请求与响应日志移除查询参数，不再记录搜索词。

## 修复

- 从二级配置页返回模块主页时丢失滚动位置：现在按页面保存并恢复滚动位置，关闭面板后清空。
- 代理模式等单选弹窗下方出现大片空白、占满屏幕：底部留白控件改为固定 8dp 高度，不再占满剩余空间。
- 长确认文案与过滤规则编辑弹窗增加限高滚动；滚动区测量遵守父布局剩余高度。
- 简介翻译弹窗增加宽度上限，并按实际布局宽度测量内容高度。

## 界面调整

- **翻译目标语言入口合并**：语言选择入口嵌入「简介与小说翻译」控件，显示当前目标语言，点击弹窗切换；不再占用独立设置行，右侧开关仍单独控制翻译功能。

## 注意

- 备份密码保存在宿主应用私有配置中，并非 Android Keystore 加密存储；Root 或能读取宿主私有目录的工具仍可能访问它。
- 备份文件加密不替代网络传输安全；使用 WebDAV 时建议开启 HTTPS。
