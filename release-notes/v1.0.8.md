# PixivPlus 1.0.8 更新日志

版本：1.0.8（versionCode 9）  
适配宿主：Pixiv Android `jp.pxv.android` 6.192.1

## 新增

- **Web 端 R-18 / R-18G 设置**：直接读取、修改当前 Pixiv 网页账号的阅览限制，显示网页账号 UID，保存后重新读取确认。开启 R-18G 同时开启 R-18，关闭 R-18 同时关闭两项；不绕过官方年龄限制。
- **底栏精简**：主页、搜索、关注新作品、通知、个人首页可逐项隐藏，至少保留一个可用入口。隐藏当前选中项时切换至可用入口，恢复全隐藏或不兼容配置时也保留入口。
- **个人首页精简**：针对主页底栏打开的个人首页，可隐藏会员／投稿按钮、我的作品、收藏、浏览历史、小说书签、关注、粉丝、好P友、屏蔽设置、帮助和关于；保留账号信息、查看个人资料与设置入口，不影响用户详情页。
- **统一精简标签页**：侧边栏、底栏、个人首页精简合并至「界面精简」，在同一设置页通过顶部标签切换。三项开关及隐藏清单仍独立，保留已有设置；当前面板会话记住所选标签及各标签滚动位置。
- **原始简介链接点击**：插画／小说简介无需打开翻译弹窗即可点击 HTTP(S) 地址、Pixiv 作品／用户引用和 HTML 命名链接。Pixiv 引用优先在宿主内打开，失败退回网页。独立开关默认开启，不依赖翻译或简介修复开关。

## 修复与优化

- **侧边栏通知重新出现**：不再依赖宿主已混淆的菜单变化方法；拦截已识别主侧边栏菜单项的动态显示，并在绘制前补查新建／重建菜单，保持切换页面后的隐藏规则。
- **简介格式与链接保留**：缓存、渲染原始 HTML，不再提前剥离外部链接及内联格式。仅在 HTML 解析文字与实际显示逐字相同时补回链接范围；保留宿主已有可点击内容和文本选择，重复绑定不叠加模块链接。
- **链接目标校验**：按实际域名和路径识别 Pixiv URL，不把相似域名、用户信息或查询内嵌路径误判为站内深链；不新增 `javascript:`、`file:`、`content:`、`intent:` 等 HTML 链接。无法打开时显示提示，日志不记录链接地址。
- **稳定源码指纹**：诊断页显示 `src-…` 构建标识，源码、资源和主要构建配置未变时保持稳定，避免仅因构建时间变化触发重复编译与 lint。该标识不是 APK 校验值或构建时间。
- **本地构建流程**：新增 `scripts/build.ps1`，固定 JDK17、独立输出目录并复用 Gradle daemon，日志写入文件；检查通过后自动安装调试包并仅重启 Pixiv。日常构建保留测试／lint，`-Full` 额外构建 Release；脚本互斥避免自身并发构建。
- **中英文文案**：新增功能提供内置中英文；已有 JSON 语言包缺少新文案时回退英文，语言包格式不变。

## 注意

- Web 阅览设置使用宿主内置 WebView 的有效登录会话，可能与 App 或外部浏览器账号不同。未登录、会话过期或官方未确认年满 18 岁时不能修改；不会更改账号生日。本版不包含试验后已回退的内置重新登录窗口，仍保留官方网页设置入口。
- 开启年龄限制作品时，Pixiv 官方可能同时开启敏感内容显示。保存后已打开的作品页面可能需要刷新；官方接口变更时模块会提示失败或无法确认结果。
- 底栏／个人首页精简默认关闭，初始不隐藏任何项。个人首页当前仅适配 Pixiv 6.192.1 的 Compose 实现；修改后请离开再进入，若宿主保留页面可能需要重启。分组标题及间距可能仍保留，未知宿主版本保留原页面。
- 关闭简介链接增强只移除模块新增链接，不移除宿主原有链接。超长简介或无法安全对齐的命名链接不强行增强；服务端未提供的简介仍需简介修复功能获取。
- 无改动的暖构建完整复跑曾实测约 4.5 秒；这是增量缓存有效的特定场景，不包含安装时间，也不代表源码变更后的构建均可在数秒内完成。
- 自动化回归与安装成功不等于全部功能已在设备实测通过，实际存储、页面、链接点击和返回行为以用户设备测试为准。
