# PixivPlus 1.0.3 更新日志

## 新增

- **小说保存**：小说阅读页右上角菜单新增「保存为 PDF」「保存为 TXT」
  - PDF 兼容带插图的作品：随作品上传的插图与引用的 pixiv 插画按原位置嵌入，下载失败自动占位
  - TXT 只保留纯文本，插图位置以 `[插图 N]` 占位
  - 首次保存通过系统文件夹选择器选择保存位置（SAF 授权仅保留在本机），之后直接保存，同名覆盖
- **简介与小说翻译**：使用 Google 翻译免费接口（无需密钥，请求沿用模块代理设置），默认关闭，目标语言可选（简中 / 繁中 / 英 / 日 / 韩）
  - 详情页「翻译简介」：弹窗对照原文与译文，可选中复制
  - 小说阅读页「翻译小说」：整篇翻译后直接替换正文显示，「显示原文」一键还原
  - 长文本按段落 / 句子自动分块，带进度提示，译文内存缓存

## 修复

- 浏览记录只显示最近 30 条：本地历史按请求偏移量分页注入，并在服务端 `next_url` 上续接下一页，可继续加载更早的记录
- 插画详情页误显示「保存为 PDF / TXT」菜单项（菜单注入现已限定在小说阅读页）
- 翻译 / 导出小说时会混入标题区、收藏按钮、系列链接、作者说明等内容：现精准定位正文容器，只处理正文
- 被屏蔽简介的插画检测不到简介：简介读取增加回退链（当前页实体 → 界面已渲染文本 → 本地简介索引）
- 左右滑动切换插画后，「翻译简介」可能读取相邻作品简介的问题
- 翻译弹窗高度不随译文自适应的问题
- 主页底部导航被注入菜单项的问题

## 改进

- 弹窗动画重写：MD3 风格缩放淡入 / 淡出退场，统一应用到确认、单选、标签多选、过滤规则编辑、浏览历史与翻译弹窗
- 翻译与图片下载双通道：模块网络栈失败时自动退回宿主网络栈（系统代理 / App 代理）
- 「让 Pixiv App 也走此代理」与设置面板页面切换动画延续 1.0.2 的能力并持续优化
