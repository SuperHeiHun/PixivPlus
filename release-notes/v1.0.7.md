# PixivPlus 1.0.7 更新日志

版本：1.0.7（versionCode 8）  
适配宿主：Pixiv Android `jp.pxv.android` 6.192.1

## 新增

- **JSON 界面语言包**：APK 仅内置简体中文和 English。模块设置中可跟随 Pixiv、手动选择语言，以及导入、更新或移除本地 JSON 语言包；缺少的译文回退英文，无需重新编译模块。
- **语言包安全校验**：只读取文案，不加载代码。校验 UTF-8、JSON 格式、重复键、语言标签及占位符编号／类型／出现次数；最多导入 16 个包，单包不超过 256 KiB。内置语言不可覆盖，重新导入同一语言标签可更新自定义包。
- **默认下载目录**：小说 TXT/PDF、插画原图/ZIP 和 GIF 默认保存到系统公共 `Download/PixivPlus`（通常为 `/sdcard/Download/PixivPlus`），不再要求首次选择目录。原图不打包时仍创建独立作品文件夹。
- **恢复默认保存位置**：已有手动选择的目录继续优先使用；小说和插画保存设置均可恢复默认下载目录，不迁移或删除以前保存的作品。
- **任务列表打开文件**：新成功任务记录实际文件 URI 和类型，可通过系统查看器打开 TXT、PDF、图片、ZIP 或 GIF；多文件任务先选择要打开的文件，仅向查看器授予读取权限。

## 修复与优化

- **小说导出排版**：区分作者换行与 DOM 布局边界，避免额外空行；保留正文缩进、行尾空格、首尾及分页处的作者留白，不再删除图片前空行或跳过短链接正文。只有空白的加载内容不导出。
- **通知任务列表返回位置**：通知入口改为复用最近的 Pixiv 页面，在该页面上显示任务列表，不再固定把 Pixiv 主页移到栈顶；关闭列表后可继续浏览之前的页面。仍显示的通知入口会随宿主页面变化更新，保留取消操作与结束通知原过期时间。
- **实时界面文案**：设置、侧边栏、作品菜单、任务状态、通知、备份与下载／翻译提示使用当前模块语言；切换语言时更新入口和通知频道名称，不重置用户对频道声音、振动等设置。
- **独立进度数据**：任务进度的数值与文案分离，不再从翻译后的字符串解析进度；作品翻译目标名称随界面语言更新，目标语言代码不变。
- **安全文件写入**：Android 10 及以上默认目录通过 MediaStore 写入，完成前隐藏半成品，失败或取消只回滚本次创建的文件；自选 SAF 目录继续支持，不提前删除同名旧文件。

## 注意

- Android 8–9 使用默认公共目录需要 Pixiv 已有存储权限；没有权限时可在模块设置中手动选择 SAF 目录。不会自动强制授予宿主权限。
- 旧下载历史没有保存文件 URI，无法可靠补齐「打开文件」，重新下载后可使用。文件被移动、删除或目录授权失效时，打开会提示不可读；需要安装对应类型的查看器。
- 界面语言不改变 Pixiv 自身语言或作品翻译目标。语言包与语言选择仅保留在本机，不写入模块备份，也不受模块缓存清理影响。历史标题、错误详情和已经导出的文件不重新翻译。
- TXT 是纯文本，不保留字体、CSS、注音或实际图片；插图仍以文本占位。译文分组遇到服务端合并／拆行时的降级策略未改变，不承诺逐行排版完全一致。
- 任务运行在宿主进程内；宿主进程已终止等情况下没有可复用页面，通知入口仍回退主页。
- 语言包格式、英文模板和不内置的日文示例见 [语言包编写说明](https://github.com/SuperHeiHun/PixivPlus/blob/v1.0.7/docs/i18n/README.md)。
