# PixivPlus 1.0.2 更新日志

## 新增

- **数据备份**：支持备份到本地文件夹（系统文件夹选择器授权）或 WebDAV 服务器
  - 备份内容：模块配置、浏览历史、作者资料（UTF-8 JSON）
  - WebDAV 备份目录可自定义（默认 `/PixivPlus/`），文件名 `pixiv-backup-yy-MM-dd_HH-mm.json`
  - 恢复前二次确认；代理密码、WebDAV 密码与本地文件夹授权不写入备份，恢复时保留本机现有值
- **App 代理**：新增「让 Pixiv App 也走此代理」，宿主 App 的全部网络请求（OkHttp / HttpURLConnection）都会经过模块代理；HTTP 代理返回 407 时自动携带 Basic 认证重试
- **代理认证**：HTTP / HTTPS 代理支持 Basic 认证，SOCKS5 支持用户名 / 密码（RFC 1929），SOCKS4 支持 USERID；代理设置页提供连通性测试
- **二级设置菜单**：设置主页按「功能 / 网络与数据 / 其他」分组并展示实时摘要（规则数、代理模式、备份状态等），点按进入二级页；关于页新增 GitHub 仓库入口
- **过滤规则弹窗编辑**：关键词 / 标签 / 作者规则在独立弹窗中编辑，附输入示例

## 改进

- 全新 Material Design 3 界面：浅色 / 深色主题自适应，组件纯代码自绘，设置面板页面切换带滑入过渡动画
- 插画简介修复：恢复被应用商店合规策略隐藏的含链接简介，本地索引优先、网页接口兜底，请求走模块代理
- 网络层重构：所有模块请求统一走自建客户端，支持任意 HTTP 方法（PUT / PROPFIND / MKCOL），WebDAV 备份在各类代理下均可用

## 修复

- 设置面板打开动画期间遮罩先消失 / 闪烁的问题（面板窗口不再叠加遮罩）

## 其他

- 模块更名：PixivLocalPlus → **PixivPlus**
