# PixivPlus 1.0.6 更新日志

版本：1.0.6（versionCode 7）  
适配宿主：Pixiv Android `jp.pxv.android` 6.192.1

## 新增

- **插画原图保存**：支持全部保存或自定义选图，提供缩略图预览、点选、全选、清空及页码输入（如 `1,3,5-8`）；下载原图，不使用缩略图替代。
- **ZIP 打包与作品目录**：可将所选原图打包为 ZIP；不打包时创建作品文件夹，原图字节不重新压缩。
- **ugoira 保存为 GIF**：按帧顺序和时长导出循环 GIF。
- **自定义保存命名**：默认使用 `作者_标题`，支持固定名称及 `{author}`、`{title}`、`{id}` 模板，图片自动追加从 1 开始的页码。
- **可选作者与作品链接**：开启后在 ZIP／作品目录内加入 `作品信息.txt`，默认关闭。
- **小说保存内容选择**：TXT／PDF 保存时可选择原版或翻译后保存，译文使用当前目标语言，不改变阅读页显示内容。
- **任务通知与取消**：下载、保存及翻译任务提供默认静默的进度通知；点击通知打开任务列表，通知内可取消任务，通知可在模块中关闭。
- **侧边栏任务列表**：查看进行中的下载／翻译及下载历史，并取消任务；侧边栏入口和历史记录可独立关闭，入口也可被侧边栏精简隐藏。
- **下载历史作品跳转与重试**：新记录可直接打开对应插画，未完成任务可继续下载，也可选择重新开始下载。
- **流式断点续传**：原图与动图 ZIP 下载中断后保留已接收字节，使用 Range／If-Range 继续，并校验响应位置、长度及验证信息；已完成图片可复用。
- **模块缓存清理**：可清理下载断点、导出临时文件、旧调试缓存，以及预览和翻译内存缓存，不删除已保存作品、设置、历史或宿主缓存。
- **作品操作菜单快捷屏蔽作者**：图文作品操作弹窗追加作者屏蔽按钮，绑定对应作品，确认后添加规则；过滤总开关关闭时不注入。

## 修复与优化

- 修复小说翻译后配图丢失：保留原文 DOM，使用独立译文层显示，并保留图片位置。
- 改善小说翻译排版：本地保留空行、章节、分页和插图，按结构回填译文。
- 优化小说翻译速度：跨空行批量翻译，最多三路并发，减少短段落产生的小请求。
- 修复小说保存混入评论、简介、推荐等非正文内容：严格限定已知正文容器，无法定位时提示重试，不再保存整页。
- 简介翻译弹窗支持点击 `ilust/123`、`illust/123` 等作品引用、小说／作者引用及 URL。
- 修复保存命名正则在 Android ICU 上导致的闪退，并对无效命名配置增加提示。
- 统一详情菜单排序，避免翻译简介与原图保存按钮因注入先后改变位置。
- 修复侧边栏直达任务列表的返回箭头跳到模块主页，现返回宿主打开位置。
- 修复通知正文未配置跳转、取消广播无法匹配，以及任务列表刷新可能吞掉取消点击。
- 下载／保存取消时清理本次导出半成品，不删除旧下载；小说保存不再提前删除同名旧文件。

## 注意

- GIF 使用 256 色调色板，色彩会与原动图有所差异，帧时长精度为 10ms。
- 断点续传覆盖原图和动图 ZIP 的网络下载阶段；ZIP 打包和 GIF 转换会重新执行。小说导出和翻译不支持断点续传。
- 旧下载历史没有作品 ID 和重试参数，不能补齐作品跳转或续传功能；新下载记录支持。
- 下载历史仅本机保留最近 100 条；关闭历史后不记录新下载参数，清空历史不删除已保存文件。历史和断点不写入备份。
- 清理模块缓存会删除未完成下载的断点，之后继续下载将从头开始；运行中的任务需先结束再清理。
- 任务运行在宿主 Pixiv 进程内，重启或终止宿主会中断任务；原图／动图网络数据可从历史重试。
- 通知以 Pixiv 身份显示，Android 13 及以上需允许宿主发送通知；下载及翻译请求沿用模块代理设置。
- 原图单文件最多 64 MB、单任务合计 512 MB；GIF 最多 2000 帧、单帧 400 万像素，动图 ZIP 最多 128 MB，解压帧和输出 GIF 最多 512 MB。
