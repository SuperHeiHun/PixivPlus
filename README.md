# PixivPlus

面向 Pixiv Android 客户端的 LSPosed / Xposed 模块，在本地提供过滤、历史、快捷屏蔽与界面增强能力。
设置、历史与语言包保存在宿主应用的私有目录中；导出的作品默认保存到公共 `Download/PixivPlus`，也可选择其他目录。模块不会自动上传设置与历史；翻译和用户主动发起的 WebDAV 备份会访问对应服务。

## 适配版本

| 项目 | 版本 |
| --- | --- |
| 宿主应用 | Pixiv Android 6.192.1（versionCode 67458，已实测） |
| 模块版本 | 1.0.8 (9) |
| 系统要求 | Android 8.0（API 26）及以上 |
| 框架要求 | LSPosed / Xposed，作用域需勾选「Pixiv」 |

> 模块通过 DexKit 在运行时解析宿主关键类与方法，对宿主的小版本更新有一定容忍度；升级宿主后如功能异常，请反馈对应版本号。

## 功能列表

### 1. 移除广告
屏蔽 ADG / AppLovin / Self-serve 三类广告请求与广告位，首页、搜索、详情页均不再出现广告卡片。

### 2. 本地 Premium 覆盖
强制宿主按会员身份渲染界面（无限书架、会员专属入口等）。
仅影响**客户端界面判断**，不会解锁服务端权限；请仅在备用账号上测试。

### 3. 本地过滤
按规则隐藏不想看到的内容，规则可随时在设置页编辑：

- 标题 / 简介关键词
- 标签（支持日文与翻译名）
- 作者：支持 UID（纯数字，精确匹配，推荐）或作者名 / Pixiv ID（account）
- 可选「区分大小写」

过滤在接口响应层生效，被隐藏的内容不会出现在首页推荐、搜索结果、排行榜等列表中。
宿主「屏蔽设定」页底部提供「PixivPlus 屏蔽项管理」入口，点按直达模块过滤规则页（本地过滤关闭时不显示；面板内返回键回到屏蔽设定页）。

### 4. 详情页快捷屏蔽
在插画 / 漫画 / 小说详情页的「更多选项」菜单中新增三个快捷项：

- 按 Tag 屏蔽：多选当前作品的标签后加入屏蔽列表
- 屏蔽当前作者：优先记录作者 **UID**（精确匹配，作者改名后依然生效；作者信息缺失时退回名称）
- 屏蔽当前标题
- 「屏蔽作者 / 屏蔽标题」点击后先弹出确认弹窗，展示将写入的规则并提示撤销方式；已在规则中的目标不会重复添加

左右滑动切换作品后，菜单会自动适配**当前显示**的作品（每个分页拥有独立工具栏，模块会逐页注入菜单项）。

### 5. 本地浏览历史
- 记录插画 / 漫画 / 小说的访问历史，只记录当前正在浏览的作品，不受预加载影响
- 支持「暂停记录」、设置保留天数（0 表示永久保留）
- 设置页内以弹窗形式查看历史列表，支持一键清空全部历史

### 6. 个人首页浏览记录联动
在原版「浏览记录」页面中展示本地历史记录，与宿主自身的浏览记录共存。

- 按桥接自己的偏移参数逐页读取本地历史，不再重复注入最近记录
- 本地记录未取完时在服务端 `next_url` 上续接下一页，可继续下拉加载更早的记录

### 7. 热门搜索修复
「按热度排行」原本对非会员账号会被服务端降级为「最新作品」。
模块在开启「本地 Premium 覆盖」时改用 `popular-preview` 接口，使热门榜返回真正的热度排序结果。

### 8. 插画简介修复
Android / iOS 版 Pixiv 为满足应用商店合规要求，会隐藏包含 URL 的简介文本。
模块会从列表响应中的原始简介或网页版接口恢复完整内容，并在插画详情页重新渲染：

- 优先使用已缓存的列表响应，无需额外网络请求
- 本地没有可用简介时，异步请求网页版 `ajax/illust` 接口兜底
- 仅当恢复内容比当前简介更长时替换，不影响正常作品
- 可在设置面板中单独关闭

### 9. 网络代理
模块自身的网页请求（如简介兜底）可独立选择代理：

- 跟随系统：沿用 Android 的 Wi-Fi / 全局 HTTP 代理
- 直连：绕过系统代理
- HTTP / HTTPS：HTTP 请求直接转发，HTTPS 请求通过 `CONNECT` 隧道
- SOCKS4 / SOCKS4a / SOCKS5：自建握手实现，支持域名目标
- 支持自定义地址与端口，并提供「测试代理连接」按钮
- 支持认证：HTTP / HTTPS 使用 Basic 认证，SOCKS5 使用 RFC 1929 用户名 / 密码，SOCKS4 使用 USERID
- 认证凭据以明文保存在 Pixiv 的私有配置中，模块请求与 App 代理共用

开启「让 Pixiv App 也走此代理」后，宿主 App 的网络请求同样经过该代理：

- OkHttp 客户端在构建时注入代理（含 407 时的 Basic 认证自动重试）
- 其余请求通过进程级 `ProxySelector` 接管
- 「跟随系统」模式不接管（App 本就使用系统代理）；直连模式会忽略系统代理强制直连
- 受 Android 限制：App 代理不支持 SOCKS4，SOCKS5 暂不支持账号密码认证

### 10. 小说保存（PDF / TXT）
在小说阅读页右上角菜单中新增「保存为 PDF」「保存为 TXT」：

- 正文直接从阅读页已加载的 WebView 中提取，不额外请求网络；登录限定、R-18 作品同样可用
- PDF 兼容带插图的作品：正文中的插图按原位置嵌入（模块网络栈优先，失败时退回宿主网络栈）
- TXT 只保留纯文本，插图位置以 `[插图 N]` 占位
- 默认保存到 `Download/PixivPlus`，可通过系统文件夹选择器改用其他位置（SAF 授权持久保留在本机）
- 文件名格式：`小说_标题_作品ID.pdf / .txt`，同名时由文件提供方创建新文件，避免取消新任务破坏旧下载
- 可在「设置 → 功能开关 → 小说保存」关闭；「小说保存」页可查看 / 更换保存位置

### 11. 简介与小说翻译
通过详情页 / 阅读页右上角菜单使用 Google 翻译（免费接口，无需密钥，沿用模块代理设置）：

- 「翻译简介」：插画与小说详情页可用，弹窗对照原文与译文（可选中复制）
- 「翻译小说」：小说阅读页整篇翻译，译文直接替换阅读页内容（保留图片占位）
- 「显示原文」：一键还原阅读页原始内容
- 长文本按段落 / 句子自动分块串行翻译，结果在内存中缓存，重复翻译不重复请求
- 目标语言可选：简体中文 / 繁體中文 / English / 日本語 / 한국어
- 默认关闭；在「设置 → 功能开关 → 简介与小说翻译」开启，点击控件内的「目标语言」入口弹窗选择语言

### 12. 数据备份
模块数据可备份到本地文件夹或 WebDAV，备份内容范围可自由勾选：

- **备份内容范围**：设置项 / 屏蔽规则（关键词、标签、作者）/ 历史记录（浏览历史与作者资料）三类分别开关，未勾选的内容不写入备份，恢复时保留本机现有值
- **备份密码加密**：设置密码后备份以 AES-256-GCM 加密（PBKDF2 派生密钥、随机盐与 IV）；密码仅保存在本机、不写入备份，恢复加密备份时自动提示输入；忘记密码将无法恢复
- 本地备份：通过系统文件夹选择器指定目录，授权仅保留在当前设备
- WebDAV：填写服务器 IP 与端口，可选 HTTPS、Basic 认证与自定义备份目录（默认 `/PixivPlus/`）
- 备份为 UTF-8 JSON，文件名统一为 `pixiv-backup-yy-MM-dd_HH-mm.json`
- 恢复前二次确认，会覆盖备份中包含的内容
- 代理密码、WebDAV 密码、备份密码、本地备份文件夹与小说保存位置不写入备份，恢复时保留本机现有值

### 13. 日志隐私
模块日志只记录事件类型、计数与长度，不包含作品标题、作者、简介片段等用户内容：

- API 响应体不再写入调试文件（旧版本会缓存到应用缓存目录）
- 搜索请求日志只记路径，搜索词不会出现在日志中
- 日志仅保存在内存与宿主私有目录，可在诊断页导出 / 清空

### 14. 侧边栏精简
在主页左侧抽屉菜单末尾注入「精简侧边栏 / 恢复全部菜单」按钮，一键隐藏低频菜单项（投稿作品、你的作品、收藏、书签、关注 / 粉丝等）：

- 隐藏清单可在「PixivPlus 设置 → 界面精简 → 侧边栏」中逐项勾选，分组标题同样按普通项处理
- 切换即时生效并持久保存；关闭后恢复全部菜单
- 按菜单项资源名（`drawer_menu_*`）识别，与宿主界面语言无关

### 15. 模块设置面板
模块入口注入在宿主「设置」页面底部，打开后采用二级菜单：

- Material Design 3 风格界面，自动适配浅色 / 深色主题，页面切换带滑入过渡动画
- 主页按分类展示状态汇总（过滤规则数、代理模式、备份状态等），点按进入二级设置
- 功能开关（浏览历史 / 过滤 / Premium 覆盖 / 广告移除 / 简介修复 / 小说保存 / 翻译 等）
- 界面精简（通过侧边栏、底栏、个人首页标签分别配置开关和隐藏项）
- 过滤规则编辑
- 小说保存（保存位置选择与说明）
- 网络代理设置与连通性测试
- 数据备份（本地文件夹 / WebDAV）
- 浏览历史查看与清理（28dp 圆角弹窗，带背景遮罩）
- 诊断信息（各功能 Hook 状态、已处理请求数等）
- 关于页面提供 GitHub 仓库入口

### 16. 插画原图与动图保存
插画详情页顶部菜单及作品操作弹窗新增「保存原图 / ZIP」，ugoira 动图另有「保存 GIF」：

- 支持全部保存或自定义选图：缩略图预览点选，也可输入页码（从 1 开始，例如 `1,3,5-8`）
- 默认按 `作者_标题` 命名，图片自动追加 `_p页码`；不打包 ZIP 时，新建作品文件夹保存所选原图
- 「自定义保存命名」支持固定名称或 `{author}`、`{title}`、`{id}` 模板，适用于图片、ZIP、GIF 和作品文件夹
- 「附带作者和作品链接」默认关闭；开启后在 ZIP / 作品文件夹内加入 UTF-8 的 `作品信息.txt`
- 仅下载 `original` 地址，原图与 ZIP 中的图片保持原始字节，不使用缩略图替代
- ugoira 按元数据中的帧顺序与时长转换为循环 GIF；GIF 使用 256 色，色彩会与原图有所差异，时长精度为 10ms
- 默认保存到 `Download/PixivPlus`；「设置 → 插画与动图保存」可更换保存位置或恢复默认，保存位置仅保留在本机、不写入备份
- 新功能可在「功能开关」中关闭；图片下载沿用模块代理，缺少原图信息时使用宿主登录态请求详情
- 每次原图下载合计最多 512 MB；GIF 最多 2000 帧、单帧 400 万像素，超出限制时提示失败
- 作品操作弹窗另新增「屏蔽作者」，绑定弹窗对应作品的作者，二次确认后添加 UID 规则；过滤总开关关闭时不注入

### 17. 任务通知与任务列表
任务成功后可在列表中「打开文件」；多图任务会先选择文件，通过系统查看器打开并仅授予读取权限。旧历史没有记录文件 URI，无法可靠补齐打开入口，需要重新下载。
- 原图 / ZIP / GIF、小说保存和简介 / 小说翻译提供进度通知，默认使用独立的静默频道，通知内可取消任务
- 「设置 → 任务列表」可关闭任务通知；关闭后仍可在任务列表取消，Android 13 及以上需允许宿主 Pixiv 发送通知
- 侧边栏新增「PixivPlus 任务列表」，入口可单独关闭，也可在「界面精简 → 侧边栏」隐藏
- 显示进行中的下载 / 翻译，下载历史可独立开关；仅本机保留最近 100 条，不写入备份，清空历史不删除文件
- 取消时关闭网络连接、停止后续处理，清理导出半成品；原图/ZIP/GIF 的网络断点保留，不删除旧下载
- 下载历史新增「打开插画」、未完成任务「继续下载」、所有有重试参数任务「重新开始下载」；新记录保存作品 ID 和选页/命名/保存格式等参数，旧历史不含 ID 的记录不能直接跳转或续传
- 原图与动图 ZIP 采用流式 `Range` / `If-Range` 下载，校验 `Content-Range`、长度及服务器验证信息；已完成图片不重复下载，服务器不支持 Range 时安全改为从头写入
- 任务运行在宿主进程中，重启或终止 Pixiv 会中断任务；未完成的下载记录在下次启动标为中断，可继续下载网络数据，ZIP 打包与 GIF 转换从头重新执行
- 「模块缓存」可清理下载断点、导出临时文件、旧调试响应及预览/翻译内存缓存；清理时必须没有运行中的任务，不删除已保存作品、设置、历史、宿主缓存或模块原生库

### 18. 界面语言与 JSON 语言包（1.0.7）

- 在「PixivPlus 设置 → 界面语言」跟随 Pixiv 或单独选择语言。仅内置简体中文和英文，其他语言通过本地 JSON 导入，缺少的译文使用英文。
- 自定义语言包不影响 Pixiv 自身或作品翻译的语言。参见 [编写说明、英文模板与示例](docs/i18n/README.md)。

### 19. 默认下载目录

- 小说 TXT/PDF、插画原图/ZIP、GIF 默认保存到系统公共 `Download/PixivPlus`（通常为 `/sdcard/Download/PixivPlus`），无需首次选择目录。
- 之前手动选择的目录仍优先使用；保存设置中可「恢复默认下载目录」。原图不打包时仍为每个作品建立独立文件夹，同名保存不覆盖已有作品。
- Android 10 及以上通过 MediaStore 写入，完成前隐藏半成品，失败或取消仅回滚本次创建的文件。Android 8–9 默认目录需要 Pixiv 的存储权限；没有权限时可手动选择 SAF 目录。

### 20. Web 端 R-18 / R-18G 设置（1.0.8）

- 「PixivPlus 设置 → Web 端 R-18 / R-18G 设置」直接读取、修改网页账号阅览设置；不是模块本地过滤。保存后重新读取确认结果，失败或结果不明时必须刷新。
- 使用宿主内置 WebView 的 Pixiv 登录会话，显示网页账号 UID；它可能与 App 或外部浏览器账号不同。未登录时需先通过 Pixiv 内置网页登录，外部浏览器登录不共享会话。
- 遵守官方年满 18 岁及生日设置要求，不绕过年龄限制。开启 R-18G 会同时开启 R-18，关闭 R-18 会同时关闭两项；官方也可能随之开启敏感内容显示。
- 请求沿用模块代理，不自动修改账号生日、不持久保存 Cookie/CSRF 或阅览状态，也不加入备份。已打开页面可能需要刷新；官方接口变化可能导致读取或保存失败，页面保留官方网页设置入口。

### 21. 底栏精简（1.0.8）

- 「PixivPlus 设置 → 界面精简 → 底栏」逐项隐藏主页、搜索、关注新作品、通知、个人首页，默认关闭。
- 至少保留一个入口；恢复全隐藏配置时也会保留宿主实际可用入口。隐藏当前选中入口时切换至可用入口，不删除页面、不影响侧边栏配置。

### 22. 个人首页精简（1.0.8）

- 「PixivPlus 设置 → 界面精简 → 个人首页」仅针对主页底栏打开的个人首页，不处理自己或作者的用户详情页，也不改变侧边栏。
- 默认关闭且初始不隐藏任何项。可隐藏会员/投稿按钮、我的作品、收藏、浏览历史、小说书签、关注、粉丝、好P友、屏蔽设置、帮助、关于；保留账号信息、查看个人资料和设置入口。
- 修改后离开个人首页再进入；若宿主保留 Compose 页面，可能需要重启。分组标题和间距可能仍保留。当前仅适配 Pixiv 6.192.1，映射校验失败或未知版本保留原页面。

### 23. 统一精简标签页（1.0.8）

- 三项精简统一在「PixivPlus 设置 → 界面精简」，通过固定在顶部的「侧边栏 / 底栏 / 个人首页」标签切换，不再分散为三个设置入口。
- 每项仍使用独立开关和隐藏清单，已有设置直接保留，无需迁移；当前设置面板会话记住所选标签和各自滚动位置，切换界面语言也保留。

## 安装步骤

1. 安装并启用 LSPosed（或其他 Xposed 框架）
2. 安装本模块 APK，在 LSPosed 中启用模块并勾选作用域「Pixiv」
3. 强制停止并重新打开 Pixiv
4. 进入 Pixiv「设置」页面，底部点击「PixivPlus」打开模块面板

## 构建

诊断页的 `src-…` 构建标识由源码、资源和主要构建配置的内容计算；相同输入保持不变，避免每次构建时间变化触发重复编译。该标识不代表构建时间或 APK 文件校验值，也不包含签名凭据；Debug/Release 可共享同一源码标识。

Windows 本地开发推荐使用 `scripts/build.ps1`：固定 JDK17、独立输出目录、单 worker、Kotlin in-process，复用 Gradle daemon（空闲 10 分钟退出）。默认构建 Debug 并执行单元测试/lint；通过后自动安装到 `emulator-5554`，确认版本并仅重启 Pixiv，不修改 LSPosed DB。构建失败、测试失败或 lint 有错误时不安装。脚本互斥避免本脚本的并发构建；不要同时手动向同一输出目录运行 Gradle。

```powershell
.\scripts\build.ps1                         # 日常开发：Debug＋测试＋lint，随后安装
.\scripts\build.ps1 -Full                   # 完整验收：额外构建 Release，随后安装 Debug
.\scripts\build.ps1 -Full -Profile          # 额外生成 Gradle 任务耗时报告
.\scripts\build.ps1 -NoInstall              # 只构建检查，不操作设备
```

日志默认 `build-latest.log`，可用 `-Log` 指定；JDK/SDK 自动探测，也可用 `-JavaHome` / `-SdkRoot` 指定。该流程不推送或发布，完整发布前仍需执行 `-Full`。

```bash
./gradlew assembleDebug      # 调试包 -> app/build-out/outputs/apk/debug/
./gradlew assembleRelease    # 发布包 -> app/build-out/outputs/apk/release/
./gradlew testDebugUnitTest lintDebug   # 单元测试与静态检查
```

CI（`.github/workflows/release.yml`）会在推送 `v*` 标签时自动构建发布包并创建 GitHub Release，附件与 artifact 统一命名为 `PixivPlus-<版本号>.apk`。

## 已知限制

- 本地 Premium 覆盖只改变本机界面判断，不会解锁服务端限制功能
- 热门搜索改写依赖「本地 Premium 覆盖」开关，关闭后热门榜会退回宿主默认行为
- 简介修复仅处理插画，暂不处理小说；网页兜底对登录限定 / R-18 作品可能受账号 Cookie 影响
- 侧边栏精简会拦截已识别菜单项的动态显示，并在主抽屉绘制前补查菜单重建，避免切换页面或通知更新后重新出现；宿主菜单结构变化仍可能影响兼容性
- 网络代理仅作用于模块自身的网页请求，不改变 Pixiv 主程序的网络连接；认证凭据以明文保存在宿主私有配置中
- WebDAV 备份目录需服务器支持 `MKCOL` / `PROPFIND`（标准 WebDAV 服务均支持）
- 备份不包含代理密码、WebDAV 密码与本地文件夹授权；跨设备恢复后需重新填写与选择
- 本地备份依赖系统文件夹选择器授权，重装宿主或清除宿主数据后需重新选择目录
- 过滤规则与备份配置保存在宿主应用私有目录，卸载宿主应用会一并清除
