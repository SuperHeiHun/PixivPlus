# PixivPlus

面向 Pixiv Android 客户端的 LSPosed / Xposed 模块，在本地提供过滤、历史、快捷屏蔽与界面增强能力。
所有数据都保存在宿主应用的私有目录中，模块不上传任何信息。

Telegrim频道：<https://t.me/HeiHun_Sub>

## 适配版本

| 项目 | 版本 |
| --- | --- |
| 宿主应用 | Pixiv Android 6.192.1（versionCode 67458，已实测） |
| 模块版本 | 1.0.3 (4) |
| 系统要求 | Android 8.0（API 26）及以上 |
| 框架要求 | LSPosed / Xposed，作用域需勾选「Pixiv」 |

> 模块通过 DexKit 在运行时解析宿主关键类与方法，对宿主的小版本更新有一定容忍度；升级宿主后如功能异常，请反馈对应版本号。

## 功能列表

### 1. 移除广告
屏蔽 ADG / AppLovin / Self-serve 三类广告请求与广告位，首页、搜索、详情页均不再出现广告卡片。

### 2. 本地 Premium 覆盖
强制宿主按会员身份渲染界面（无限书架、会员专属入口等）。
仅影响**客户端界面判断**，不会解锁服务端权限；请仅在备用账号上测试。

### 3. 本地过滤
按规则隐藏不想看到的内容，规则可随时在设置页编辑：

- 标题 / 简介关键词
- 标签（支持日文与翻译名）
- 作者名或 Pixiv ID（account）
- 可选「区分大小写」

过滤在接口响应层生效，被隐藏的内容不会出现在首页推荐、搜索结果、排行榜等列表中。

### 4. 详情页快捷屏蔽
在插画 / 漫画 / 小说详情页的「更多选项」菜单中新增三个快捷项：

- 按 Tag 屏蔽：多选当前作品的标签后加入屏蔽列表
- 屏蔽当前作者
- 屏蔽当前标题

左右滑动切换作品后，菜单会自动适配**当前显示**的作品（每个分页拥有独立工具栏，模块会逐页注入菜单项）。

### 5. 本地浏览历史
- 记录插画 / 漫画 / 小说的访问历史，只记录当前正在浏览的作品，不受预加载影响
- 支持「暂停记录」、设置保留天数（0 表示永久保留）
- 设置页内以弹窗形式查看历史列表，支持一键清空全部历史

### 6. 个人首页浏览记录联动
在原版「浏览记录」页面中展示本地历史记录，与宿主自身的浏览记录共存。

- 按桥接自己的偏移参数逐页读取本地历史，不再重复注入最近记录
- 本地记录未取完时在服务端 `next_url` 上续接下一页，可继续下拉加载更早的记录

### 7. 热门搜索修复
「按热度排行」原本对非会员账号会被服务端降级为「最新作品」。
模块在开启「本地 Premium 覆盖」时改用 `popular-preview` 接口，使热门榜返回真正的热度排序结果。

### 8. 插画简介修复
Android / iOS 版 Pixiv 为满足应用商店合规要求，会隐藏包含 URL 的简介文本。
模块会从列表响应中的原始简介或网页版接口恢复完整内容，并在插画详情页重新渲染：

- 优先使用已缓存的列表响应，无需额外网络请求
- 本地没有可用简介时，异步请求网页版 `ajax/illust` 接口兜底
- 仅当恢复内容比当前简介更长时替换，不影响正常作品
- 可在设置面板中单独关闭

### 9. 网络代理
模块自身的网页请求（如简介兜底）可独立选择代理：

- 跟随系统：沿用 Android 的 Wi-Fi / 全局 HTTP 代理
- 直连：绕过系统代理
- HTTP / HTTPS：HTTP 请求直接转发，HTTPS 请求通过 `CONNECT` 隧道
- SOCKS4 / SOCKS4a / SOCKS5：自建握手实现，支持域名目标
- 支持自定义地址与端口，并提供「测试代理连接」按钮
- 支持认证：HTTP / HTTPS 使用 Basic 认证，SOCKS5 使用 RFC 1929 用户名 / 密码，SOCKS4 使用 USERID
- 认证凭据以明文保存在 Pixiv 的私有配置中，模块请求与 App 代理共用

开启「让 Pixiv App 也走此代理」后，宿主 App 的网络请求同样经过该代理：

- OkHttp 客户端在构建时注入代理（含 407 时的 Basic 认证自动重试）
- 其余请求通过进程级 `ProxySelector` 接管
- 「跟随系统」模式不接管（App 本就使用系统代理）；直连模式会忽略系统代理强制直连
- 受 Android 限制：App 代理不支持 SOCKS4，SOCKS5 暂不支持账号密码认证

### 10. 小说保存（PDF / TXT）
在小说阅读页右上角菜单中新增「保存为 PDF」「保存为 TXT」：

- 正文来自网页版 `ajax/novel/{id}` 接口，支持 `[newpage]` 分页、`[chapter:]` 章节标题、注音与链接标记
- PDF 兼容带插图的作品：随作品上传的插图与引用的 pixiv 插画（`[pixivimage:]`）会下载后嵌入正文对应位置
- TXT 只保留纯文本，插图位置以 `[插图 N]` 占位
- 首次保存时通过系统文件夹选择器选择保存位置（SAF 授权持久保留在本机），之后直接保存到该文件夹
- 文件名格式：`小说_标题_作品ID.pdf / .txt`，同名文件会被覆盖
- 可在「设置 → 功能开关 → 小说保存」关闭；「小说保存」页可查看 / 更换保存位置

### 11. 数据备份
模块数据可备份到本地文件夹或 WebDAV，备份内容包含配置、浏览历史与作者资料：

- 本地备份：通过系统文件夹选择器指定目录，授权仅保留在当前设备
- WebDAV：填写服务器 IP 与端口，可选 HTTPS、Basic 认证与自定义备份目录（默认 `/PixivPlus/`）
- 备份为 UTF-8 JSON，文件名统一为 `pixiv-backup-yy-MM-dd_HH-mm.json`
- 恢复前二次确认，会覆盖当前配置、浏览历史与作者资料
- 代理密码、WebDAV 密码、本地备份文件夹与小说保存位置不写入备份，恢复时保留本机现有值

### 12. 模块设置面板
模块入口注入在宿主「设置」页面底部，打开后采用二级菜单：

- Material Design 3 风格界面，自动适配浅色 / 深色主题，页面切换带滑入过渡动画
- 主页按分类展示状态汇总（过滤规则数、代理模式、备份状态等），点按进入二级设置
- 功能开关（浏览历史 / 过滤 / Premium 覆盖 / 广告移除 / 简介修复 / 小说保存 等）
- 过滤规则编辑
- 小说保存（保存位置选择与说明）
- 网络代理设置与连通性测试
- 数据备份（本地文件夹 / WebDAV）
- 浏览历史查看与清理（28dp 圆角弹窗，带背景遮罩）
- 诊断信息（各功能 Hook 状态、已处理请求数等）
- 关于页面提供 GitHub 仓库入口

## 安装步骤

1. 安装并启用 LSPosed（或其他 Xposed 框架）
2. 安装本模块 APK，在 LSPosed 中启用模块并勾选作用域「Pixiv」
3. 强制停止并重新打开 Pixiv
4. 进入 Pixiv「设置」页面，底部点击「PixivPlus」打开模块面板

## 构建

```bash
./gradlew assembleDebug      # 调试包 -> app/build-out/outputs/apk/debug/
./gradlew assembleRelease    # 发布包 -> app/build-out/outputs/apk/release/
./gradlew testDebugUnitTest lintDebug   # 单元测试与静态检查
```

CI（`.github/workflows/release.yml`）会在推送 `v*` 标签时自动构建发布包并创建 GitHub Release。

## 已知限制

- 本地 Premium 覆盖只改变本机界面判断，不会解锁服务端限制功能
- 热门搜索改写依赖「本地 Premium 覆盖」开关，关闭后热门榜会退回宿主默认行为
- 简介修复仅处理插画，暂不处理小说；网页兜底对登录限定 / R-18 作品可能受账号 Cookie 影响
- 网络代理仅作用于模块自身的网页请求，不改变 Pixiv 主程序的网络连接；认证凭据以明文保存在宿主私有配置中
- WebDAV 备份目录需服务器支持 `MKCOL` / `PROPFIND`（标准 WebDAV 服务均支持）
- 备份不包含代理密码、WebDAV 密码与本地文件夹授权；跨设备恢复后需重新填写与选择
- 本地备份依赖系统文件夹选择器授权，重装宿主或清除宿主数据后需重新选择目录
- 过滤规则与备份配置保存在宿主应用私有目录，卸载宿主应用会一并清除
