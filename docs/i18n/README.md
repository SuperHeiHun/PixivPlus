# PixivPlus 界面语言包

APK 只内置简体中文和英文。在 **Pixiv 设置 → PixivPlus → 界面语言** 可以跟随 Pixiv、手动选择语言，或导入自行编写的 JSON。此设置不会改变 Pixiv 自身的语言或 Google 翻译的目标语言。

## 编写和导入

1. 复制 [英文模板 en.json](../../app/src/main/assets/pixivplus/i18n/en.json)，或用 [日文示例](example-ja.json) 从少数条目开始。示例文件只在仓库文档中，不打包进 APK。
2. 保留 `"version": 1`。将 `locale` 改为 BCP 47 语言标签（如 `ja`、`fr-FR`、`zh-Hant`），`name` 填写在选项中显示的语言名称。
3. 翻译 `strings` 中的值，不要更改键名。可以删除尚未翻译的键，模块会对这些条目使用英文。未知键不会显示；包中至少要有一个当前版本认识的键。
4. 保存为 UTF-8 `.json`。选择「导入 JSON 语言包」并选取文件，成功后自动选用。重新导入同一语言标签可替换原包；内置的 `en` 和 `zh-CN` 不可替换或移除。

```json
{
  "version": 1,
  "locale": "fr-FR",
  "name": "Français (France)",
  "strings": {
    "settings.language": "Langue de l’interface",
    "common.cancel": "Annuler",
    "work.page_number": "Page %1$d"
  }
}
```

### 文案规则

- 位置占位符（如 `%1$s`、`%2$d`）保留原来的编号、类型和出现次数，可调整顺序。带占位符的文案要显示百分号时用 `%%`；没有占位符的文案可直接写 `%`。
- 换行写成 `\n`。文案是纯文本，不执行 HTML、脚本或代码。文件上限 256 KiB，单条文案最多 4096 字符，最多导入 16 个包。
- 「跟随 Pixiv」优先匹配宿主语言列表中的语言标签，再尝试同语言的通用包。没有匹配的语言时回退英文；未导入繁体中文包时，中文宿主语言默认显示简体中文。
- 语言包及选择只保存在宿主的模块私有文件／配置中，重启后仍生效，不通过 WebDAV 或模块备份传输，也不会被「模块缓存」清理。移除当前选用的包会切回「跟随 Pixiv」。既有下载任务的标题、错误详情和已经导出的文件不会被重新翻译。
